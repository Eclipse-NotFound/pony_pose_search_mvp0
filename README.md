# Pony Pose Search

把图片、视频和角色工程整理成自己的素材库，标注角色的身体与肢体朝向，再用一张参考姿态寻找相似动作。搜索结果可以追溯到**原文件、视频帧号，或 FLA 的场景／元件与工程帧号**。

这是一个 Windows 桌面程序。日常操作都在同一个 M10 窗口内完成。

## 下载并打开（推荐，无需编程基础）

**[下载 Windows 64 位免安装版](https://github.com/Eclipse-NotFound/pony_pose_search_mvp0/releases/latest)**

适用于 Windows 10／11 的 64 位电脑；已在 Windows 11 x64 验证。下载包已经带好 Python 和视频读取组件，**不用安装 Python、输入命令或配置环境变量**。

1. 打开上面的下载页，在 **Assets（附件）** 中下载 `PonyPoseSearch-0.1.0-Windows-x64.zip`。后续版本的文件名会带新的版本号。
2. 在下载的 ZIP 上点右键 → **全部解压**，解压到自己容易找到的文件夹，例如 `D:\工具\PonyPoseSearch`。
3. 打开解压出来的 `PonyPoseSearch` 文件夹，双击 **`PonyPoseSearch.exe`**。
4. 看到左侧有 M01—M09 的窗口就可以开始。**首次显示 0 个素材是正常的**，下一步添加你自己的图片。

请完整解压后再运行。`_internal` 文件夹是程序的一部分，必须和 exe 放在一起；可给 exe 创建快捷方式，但不要只把 exe 移到桌面。

下载页中的 **Source code (zip/tar.gz)** 是给开发者用的源码，普通使用请选择上面带 **Windows-x64** 的附件。本版未做数字签名，Windows 可能提示来源未知；请自行核对是本仓库 Release 的附件后决定是否运行，不要关闭系统防护。

## 第一次使用：先用两张图片试一遍

先准备两张只含一个角色的 PNG 或 JPG。**图片加入目录后，还需要建立角色记录、标注并确认方向，才能按姿态搜索。**

1. **加入第一张图。** 点左侧 **M01** → **添加文件**。选中列表中的图片，点 **读取画面**。
2. **告诉程序看哪个角色。** 只有一个角色时点 **选整张图**；有多个角色时在图上拖框。勾选 **确认框内是一个角色**，选择对应角色形态，点 **建立记录 → 标注**。
3. **标记姿态。** 在 **M05** 右侧选择 **直接方向**，选中头部等需要比较的方向，在图上按起点到终点拖出箭头。画完会自动前进到下一项；**点回刚才画的方向**，核对后点 **确认此方向**，等待保存。第一次可以只标头部方向；越多共同部位完成审核，比较的信息越充分。提示部位不存在时，在 **标注属性…** 中核对并修改。
4. **再加入第二张图。** 重复以上步骤，标注相同部位。素材库里至少有另一条可比较的记录，搜索才有意义。
5. **搜索。** 选择一条已标注记录，点 **搜索此姿态 → M08**，保留默认条件，点 **搜索并查看结果**。
6. **找回原素材。** 在 **M09** 点击结果，查看原画面、角色裁剪和位置。用 **在文件夹中选中** 找到原文件；视频与 FLA 会同时显示各自的帧号。

M01—M09 是各步骤的编号，不必每次全部走一遍。批量筛选用 M02—M04；只想整理和搜索，可以先不用 M06 的训练功能。关键点标注、查询图片和批量操作见 **[完整使用指南](README_FOR_USERS.md)**。

## 不同素材需要什么

| 想处理的内容 | 下载后能否直接使用 | 从哪里开始 |
|---|---|---|
| PNG、JPG、WebP 图片 | 可以 | M01 添加文件、读取画面 |
| MP4、MOV、MKV 等视频 | 可以，已带 FFmpeg/ffprobe | M01 读取指定帧，或“批量选帧…” |
| 角色 FLA 工程 | 需要本机另装 Adobe Animate | M01 选中 FLA →“角色工程…” |
| 手动标注、按姿态搜索、导出结果 | 可以，不依赖 AI 模型 | M05、M07—M09 |
| AI 自动建议与训练 | 需要另外准备模型及 AI 环境 | [进阶说明](README_FOR_USERS.md#ai-自动标注与训练可选) |

FLA 导出支持场景与库元件时间轴，仍需筛选是否为完整角色；旧脚本驱动的动画效果不保证还原。XFL 目录渲染、SWF 解码、自动挑代表帧尚未实现。多物种结构支持小马、狮鹫、双足龙和混合身体；现有 21 点及 AI 训练器仅适用于声明支持的小马结构。

下载包**不附带动画原片、角色工程、私人标注库和模型权重**。历史验证记录里的素材数量不代表下载后预装了这些数据。

## 标注存在哪里？怎样更新？

免安装版默认资料库在 `%LOCALAPPDATA%\PonyPoseSearch\library`。把这行路径粘贴到文件资源管理器地址栏即可打开。也可点击窗口上方 **切换资料库…**，选择其他文件夹，程序会记住选择。

- **更新：** 关闭旧窗口，下载新版并解压到新的文件夹，再打开新版 exe。资料库保存在独立位置，会继续使用；原来的源码版用户可手动切到原 `data\pose_library_v2`。
- **备份：** 关闭程序后复制整份资料库，同时备份原始素材。资料库保存标注与必要预览，不代表已经备份整部视频或所有工程。
- **移除程序：** 删除解压出的程序文件夹即可，资料库仍保留。

遇到打不开、导入失败或搜索为空，请看 **[常见问题](README_FOR_USERS.md#常见问题)**。启动日志在 `%LOCALAPPDATA%\PonyPoseSearch\startup.log`。

## 开发者：从源码运行

普通使用优先下载上面的免安装版。本段只适用于希望修改代码的人。

Windows 上安装 Python 3.12（包含 Tcl/Tk），在项目文件夹打开终端：

```powershell
python -m pip install -r requirements.txt
python scripts/m10/control_center.py
```

也可双击 `run_m10.bat`。**源码版**另需 FFmpeg/ffprobe，可加入 PATH，或设置 `PONY_FFMPEG`、`PONY_FFPROBE`。FLA 可通过 `PONY_ANIMATE` 指定 Animate。源码版默认仍使用项目内 `data/pose_library_v2`。

基础自检：`python scripts/m10/control_center.py --check-ui`。回归测试：安装 `requirements-dev.txt` 后运行 `python -m pytest tests/multispecies tests/m10`，视频测试需要 FFmpeg，界面测试需要可用 Tk 桌面环境。旧实验测试需要自行准备数据。

打包步骤与版本验证见 [Windows 发布说明](docs/windows-release.md)。设计和开发记录中的本机路径、实验图片与历史数量仅供追溯，并不随发行版提供。
