# 使用指南：从第一张图片开始

如果还没有打开程序，请先按 [首页的下载步骤](README.md#下载并打开推荐无需编程基础) 下载 Windows 免安装版、完整解压，双击 `PonyPoseSearch.exe`。无需安装 Python 或视频插件。

## 先认识窗口

窗口上方显示当前资料库的位置，右上方可以切换资料库。左侧 M01—M09 是步骤编号，右侧显示当前步骤的内容。

| 想做什么 | 去哪里 |
|---|---|
| 添加图片、视频、FLA，查看画面 | M01 素材 |
| 批量筛选画面、框角色、生成样本 | M02—M04 |
| 标注身体和肢体的方向，或标关键点 | M05 |
| 准备模型训练资料（初次使用可以跳过） | M06 |
| 指定想找的姿态 | M07 |
| 设置搜索条件 | M08 |
| 查看结果，找原文件和具体帧号 | M09 |
| 查看后台处理是否完成、失败原因 | 任务日志 |

新资料库是空的，下载包不含动画原片、角色素材、标注数据或 AI 模型。程序也不会自动扫描整台电脑，只会处理你添加的文件或文件夹。

## 用两张图片完成第一次搜索

建议先准备两张清晰、各含一个角色的 PNG 或 JPG，选择当前列表中已有的角色形态。第一次可以只比较头部方向，等流程熟悉后再增加身体、前后肢和尾巴。

### 1. 添加图片，建立角色记录

1. 点 **M01 → 添加文件**，选择第一张图片。
2. 等左侧列表中的素材处理完成，选中它，点 **读取画面**。
3. 图中只有一个角色时点 **选整张图**。有多个角色时，按住鼠标左键拖框，只框住要标注的那个角色。
4. 勾选 **确认框内是一个角色**，在下拉框选择对应角色形态。
5. 点 **建立记录 → 标注**，进入 M05。

“添加文件”只是告诉程序素材在哪里；“建立记录”才是在这份素材里选出一个角色供标注和搜索。两个步骤都要完成。

### 2. 标注方向并确认

方向是一支箭头。例如头部朝右，就画一支朝右的箭头；本项目主要比较这些方向，不要求每支箭头都一样长。

1. 在 M05 右侧把模式从 **关键点** 切换为 **直接方向**。
2. 在列表中选中要标的方向，例如头部。若该部位被设为不存在，打开 **标注属性…**，选对应部位，把 **部位是否存在** 改为存在。未知部位首次画方向时会自动记为存在。
3. 在画面上按起点到终点的方向拖动鼠标，画出箭头，也可依次点起点和终点。
4. 画完后会自动前进到下一项。**点回刚才标注的那一项**，核对箭头，点 **确认此方向**；等待保存完成。确认表示“我已检查过”，普通保存不等于审核。
5. 如果还要比较其他部位，重复以上步骤。最后点 **保存**，确保没有待保存的修改。

尾巴方向表示**从身体伸出时的初始朝向**，不追着下垂或弯曲后的尾尖画。看不清的方向可以标缺失，不要凭想象补值；缺失部位不提供有效比较信息。

如果习惯点关键点，可以保留 **关键点** 模式：在右侧选点，在图中点击位置。`↑/↓` 选点、`←/→` 换图、`Ctrl+Enter` 标缺失、`Ctrl+S` 保存。再用 **生成方向…** 检查由点位算出的方向，确认后用于搜索。修改点位会使相关旧方向过期，需要重新生成并审核。已有 21 点规则只适用于支持的小马身体结构。

### 3. 加入第二张图

返回 M01，重复前两步，为第二张图片建立记录，并标注、确认相同部位的方向。添加很多未标注的图片，不会自动得到可按姿态比较的结果。

### 4. 搜索并找回原图

1. 在 M05 选择一条已标记录，点 **搜索此姿态 → M08**。
2. 第一次保留默认条件，点 **搜索并查看结果**。
3. 在 M09 点击结果，对照原画面和角色裁剪。
4. 点 **在文件夹中选中**，定位原素材；也可复制位置，或导出 CSV、JSON、离线 HTML。

默认只把已审核的有效方向用于比较。搜索为空时，先核对两张图是否都建立了记录、是否有相同且已确认的方向、角色及物种筛选是否过窄。

## 使用新的参考图查询

在 **M07 → 更换查询图片…** 选择参考图，指定角色形态并标注方向，随后到 M08 搜索。查询图用于描述“想找什么”，不会自动进入训练资料。

参考图有多个角色时，可以在 M01 框出目标角色，勾选 **仅作查询图** 后建立记录。也可以直接用库里的某个已标姿态发起搜索。

M08 的 **保存查询条件** 可以固定本次标注版本和条件；**重跑已保存查询** 沿用保存时的查询。后来修改参考图方向，需要重新保存或直接“搜索并查看结果”。

## 视频：读一帧，或批量选帧

免安装版已带 FFmpeg 和 ffprobe，无需另装。支持的常见格式包括 MP4、MOV、MKV、AVI、WebM、M4V。同一扩展名也可能使用不同编码；少数特殊编码可能无法读取，例如以 PNG 编码的视频轨。普通 PNG 图片的读取不受影响，失败时请查看任务日志。

1. 在 M01 添加视频，等待列表显示处理完成。
2. 选中视频，在“第…帧”填入帧号，点 **读取画面**。帧号从 **1** 开始。
3. 可以用 **上一帧／下一帧** 看附近动作，也可以点 **播放附近片段** 观察上下文。
4. 选中角色后建立记录并标注。要批量处理时，使用 **批量选帧…**，在弹窗中设置范围与间隔。

批量生成的画面先进入 M02。保留有价值的画面，在 M03 框角色、核对形态，再到 M04 生成样本，最后统一进入 M05。不是所有素材都按固定一秒抽一帧；请依据动作速度选范围和步长。本版还不会自动挑出所有代表动作。

M09 返回的是原视频文件和准确帧位置，角色裁剪只是便于比较的预览。外部播放器的显示时间可能经过取整，请以程序记录的帧号为准。

## FLA：从角色工程导出画面

**需要本机另行安装 Adobe Animate。** 本软件不附带 Animate，也不包含任何角色 FLA。先用你自己已有的工程试一个短范围。

1. 在 M01 添加并选中 FLA，点 **角色工程…**。
2. 选择场景，或包含完整角色的库元件。优先推荐的复合元件可能只是零件或文字，仍需看预览确认。
3. 设置起止帧，建立导出任务。程序会让 Animate 打开独立工程副本，不保存原 FLA。
4. Animate 如果询问 JSFL“运行还是编辑”，请选择 **作为命令运行**。旧 AS2 工程可能另有转换提示；核对副本后自行处理。
5. 在任务页查看进度；完成后到 M02 筛选，再按 M03—M05 的流程框选、生成样本和标注。

程序优先识别常见 Adobe Animate 安装位置。找不到时，弹窗会说明原因，可使用导出包中的 JSFL 手动导出。需要自定义路径的进阶用户可设置 `PONY_ANIMATE` 指向 `Animate.exe`。

工程帧号属于所选场景或元件的时间轴，**不等同于成片视频帧号**。M09 会同时显示时间轴名称、工程帧号和原 FLA 路径；当前不会自动在 Animate 内跳到该角色实例。

目前处理时间轴静态画面，旧脚本驱动的效果不保证还原。XFL 目录渲染和 SWF 解码尚未接入。工程任务的“暂停”暂停的是程序接收与等待，不会停止 Animate。失败或超时后先查看任务说明，不要连续重复提交；保留的副本可供排查。

更多工程接入细节见 [素材目录说明](docs/source-catalog.md#角色-fla-的操作)。

## 搜索条件怎样选

- **允许左右翻转**：默认关闭。开启后可以找到反方向的相似动作，需要翻转的结果会标出来，原素材不被修改。
- **整腿交换**：默认开启。允许两条前腿之间、两条后腿之间整条交换比较，让相似动作更容易找到。
- **部位权重**：决定更看重哪里。例如寻找抬头动作，可以增加头部权重。方向是主依据，视角与相对位置只作辅助。
- **未审核与草案规则**：初次使用保留默认。放宽它们能看到更多结果，但不能等同于已经人工确认的标注。
- **角色与物种**：缩小搜索范围。如果结果太少，先检查这些筛选是否排除了想找的角色。

## 资料保存、备份与升级

免安装版默认资料库：`%LOCALAPPDATA%\PonyPoseSearch\library`。可以把这串路径粘贴到文件资源管理器地址栏打开。窗口上方一直显示实际使用的库，可点 **切换资料库…** 改到空间更充足的位置，程序会记住选择。

资料库包含标注、历史版本、角色图片、素材位置和搜索记录。**原视频和原 FLA 仍在原来的文件夹中**，登记不等于完整备份原素材。

- 备份前关闭 M10，然后复制整份资料库及原始素材。
- 更新时关闭旧窗口，把新 ZIP 解压到新的程序文件夹，再启动新版。不要覆盖或删除资料库；建议更新前先备份。
- 原来用源码版的人，点击“切换资料库…”选择原项目的 `data\pose_library_v2`；原资料不会自动复制到默认新位置。
- 删除程序文件夹不会删除资料库。若要腾空间，请先确认原素材和标注已有可靠备份。

如果上次的资料库在移动硬盘上，请先连接硬盘再启动。程序不会在找不到旧库时悄悄建立同名空库。

## AI 自动标注与训练（可选）

基础搜索不依赖 AI。免安装版可以手动标注、审核、搜索，也可以准备和导出训练资料。**它没有预装模型、PyTorch 或 Ultralytics**，不能下载后立即自动识别所有角色。

AI 模型只对自己声明的身体结构和点位规则有效，生成的建议需要在界面中接受、修改或拒绝。当前训练验证并不代表已达到某个准确率保证。

希望使用 AI 的进阶用户，需要另外准备具有对应模型依赖的 Python 环境、登记模型，并将 `POSE_AI_PYTHON` 指向那个环境的 `python.exe`。训练弹窗也可填写解释器位置。不要把 `PonyPoseSearch.exe` 当作 Python 解释器。具体数据和模型流程见 [模块工作流](docs/module-workflow.md)。

## 常见问题

| 现象 | 先这样检查 |
|---|---|
| 下载后只有 `.py`、`.bat`，找不到 exe | 下载的是源码。回 Release 页面，选择带 Windows-x64 的 ZIP 附件。 |
| 提示 Python not found | 这是旧源码启动器的提示。使用免安装版里的 `PonyPoseSearch.exe`；不必为了它安装 Python。 |
| 提示缺少 DLL 或视频组件 | 关闭程序，重新完整解压 ZIP，保留 `_internal` 文件夹。不要直接在压缩包里运行。 |
| Windows 提示来源未知 | 本版没有数字签名。核对是否来自本仓库 Release，再由你决定是否运行；不要关闭防护，不确定时先取消。 |
| 打开后素材数量为 0 | 初次使用正常。M01 添加自己的文件；老用户请切换到原资料库。 |
| 加入素材后搜不到结果 | 先读取画面、建立角色记录、标注共同部位，并逐项确认、保存。仅登记文件不足以搜索姿态。 |
| 画了方向但默认搜索仍不采用 | 画完会自动选下一项；点回刚才画的方向，点“确认此方向”，等待保存。普通保存不自动审核。 |
| 视频或工程一直未完成 | 到任务日志查看具体错误；确认未暂停处理、原文件可访问，FLA 还需查看 Animate 是否有等待响应的弹窗。 |
| 缺少 Adobe Animate | 图片和视频仍可用。FLA 原生导出需要另装 Animate，或者使用已有导出画面。 |
| 重启找不到上次的库 | 连接原磁盘、恢复原目录。如果已主动搬库，可在 `%LOCALAPPDATA%\PonyPoseSearch\settings.json` 更新 `library` 路径；修改前先保留副本。 |
| exe 一启动就退出 | 查看 `%LOCALAPPDATA%\PonyPoseSearch\startup.log`，在 Issues 中提供错误内容与系统版本；分享前检查日志中的个人路径。 |

未解决的问题可在 [GitHub Issues](https://github.com/Eclipse-NotFound/pony_pose_search_mvp0/issues) 提交。尽量写明“点了哪个按钮、期望什么、实际出现什么”，并附相关错误截图。

## 项目现状与历史验证

当前支持统一的素材目录、角色标注、查询、搜索及位置追溯；FLA 通过本机 Animate 在工程副本上导出。自动挑代表帧、XFL 渲染、SWF 解码等仍有待实现。

历史记录中的本机素材数量和实验数据不是发行版自带内容。需要了解实现依据时，可阅读 [模块化合并验证](开发/验证记录-2026-10-13-模块化合并CDE.md)、[不同格式流程验证](开发/验证记录-2026-10-13-多格式全流程测试.md)、[角色 FLA 验证](开发/验证记录-2026-10-13-角色FLA接入.md) 和 [Windows 发布说明](docs/windows-release.md)。
