# Pony Pose Search — 用户指南

从角色姿态出发寻找相似的动画画面，并找回原素材文件、视频帧、工程时间轴帧或已有的位置线索。**方向是检索主体**，视角和相对位置辅助；尾巴表示离开身体时的初始朝向。

## 现在怎样使用

先保存并关闭旧窗口，然后双击 **`run_m10.bat`**。现在只有一套 M10 原生界面，左侧 M01—M09、模型审核和任务日志共用一个资料库。`run_pose_workbench.bat` 也打开这个窗口。

1. **M01** 添加视频、图片、FLA 等文件；图片直接读取，视频读取画面或批量选帧；FLA 点击“角色工程…”选择场景／库元件，导出待筛候选。
2. **M02—M04** 保留候选，框出一个或多个角色，核对形态和区域后生成样本。可以稍后接着处理，改框会保留旧版本。
3. **M05** 标注方向或有定义的点位，逐项审核；修改点位后受影响的派生方向会过期。模型建议也在这里修改和审核。
4. **M07** 载入并标注查询图片，或使用当前样本；**M08** 设置搜索范围、部位权重并搜索；**M09** 对照原画面与角色裁剪，找到原文件和帧号。可导出 CSV、JSON 或离线 HTML。翻转默认关闭、整腿交换默认开启。
5. **M06** 核对点位派生方向，冻结已审训练数据，导出或启动训练。方向、点位和角色检测分别取数；也能固定同图同分组的点位／方向对照。

**角色 FLA：** 在“角色工程…”中选中完整角色所在的时间轴，默认按起止范围逐帧导出；任务完成后进入 M02 筛选。推荐的复合元件只是优先预览对象，可能含零件或文字，不是审核结论。程序调用本机 Animate 处理独立副本，不保存原 FLA；找不到 Animate 时会说明原因并禁用自动导出，已导出画面仍可查看。M09 显示场景／元件名称与工程帧号，不把它当作视频帧。详见[角色 FLA 操作说明](docs/source-catalog.md#角色-fla-的操作)。

Animate 如询问 JSFL“运行还是编辑”，请选择“作为命令运行”。旧版 AS2 工程可能弹出转换提示，处理的是副本；当前接入的是时间轴静态画面，不保证旧脚本驱动的播放效果。

工程任务的暂停仅暂停程序等待和接收，不会停止 Animate。已有失败回执时从“角色工程…”重新建立导出任务，旧副本和诊断保留；超时后不会盲目重复投递。自动挑代表帧、相似画面折叠尚未实现。

2026-10-13 按进一步反馈，恢复原模块的操作方式：M05／M07 使用大图＋完整点位列表，落点后自动前进，点击已有点选中，Ctrl+Enter 标缺失，↑↓ 选点、←→ 换图、Ctrl+S 保存。换图时保存普通标注草稿（不自动审核）；模型建议仍需明确处理。M08 单独设置条件，M09 默认显示原画面＋裁剪缩略图。直接方向、多物种、素材位置和共同资料库继续保留。先保存关闭旧窗口，再启动即可。见[界面与验证记录](开发/验证记录-2026-10-13-M10界面改进.md)。

## 能力边界

- 图片、视频及成功导出的角色 FLA 画面使用同一套候选、样本、标注和检索流程。FLA 记录精确的场景／元件及工程帧，尚不在 Animate 内自动跳到角色实例；同名工程与视频仍只是候选关联。XFL 目录渲染、SWF 解码尚未接入。
- 小马、狮鹫、双足龙、混合身体支持结构与方向标注。21 点和现有模型训练器只适用于声明的小马结构，新物种不会被套成小马点位。
- query_001 缺原图；query_002 是纯色图。保留原问题，不替换图片来制造有效标签。
- 本次训练是流程验证，不能证明识别准确率提高。旧规模实验有一项来源指纹与当前旧向量文件不一致，其原始记录没有被改写。
