# 素材编目与结果定位

2026-10-13：编目归入 M01，候选、框选、样本生成分别归 M02—M04。完整使用方法见[共同流程指南](module-workflow.md)。来源实现和历史实测见[首版验证](../开发/验证记录-2026-10-12-多格式编目与来源定位实现.md)。

| 素材 | 当前能力 |
|---|---|
| PNG/JPG/WebP 等图片 | 登记、按显示方向读取、选区域、原图精确定位 |
| MP4/MOV/MKV 等视频 | 登记、选择视频流、解码取帧、批量候选、附近片段、帧序号和 PTS 定位；需要 FFmpeg/ffprobe |
| 角色 FLA | 检查主场景与库元件时间轴；调用本机 Animate 在独立副本上导出画面，接入候选、标注和搜索；位置记录源版本、时间轴及工程帧 |
| XFL | 文件编目、支持格式的结构与同名关联线索；目录依赖的原生渲染尚未接入 |
| SWF、不可解码或损坏文件 | 保留文件登记、实际能力和错误；可重试，不伪装成已经取得画面 |

文件名不是内容身份。每次源文件变化保留旧内容版本，重新定位目录也要核对文件内容。缺失文件不删除既有缓存和标注；指向改变的文件时明确说明，不拿新内容替换旧姿态。

搜索导出记录当次的文件路径、源版本、视频流或工程时间轴、从 1 开始的显示帧号／底层序号、时间戳、裁剪区域及精度。FLA 的“第 N 工程帧”属于指定场景或元件；同一数字的场景帧、元件帧和视频帧不是同一个位置。旧抽帧编号不等于真实视频帧号；旧样本逐像素吻合原图区域时可以关联到那张原图，仍不凭名称推断视频中的精确位置。同名 FLA 与 MP4 仍只是未核对的关联线索。

## 角色 FLA 的操作

1. 在 M01 添加 FLA，选中文件后点击“角色工程…”。现代 FLA 先读取存储结构；旧版 OLE FLA 需要 Animate 在副本上检查时间轴。
2. 在时间轴列表选择主场景或完整角色所在的库元件。默认展示推荐项；其中复合元件只是优先预览的对象，仍可能包含零件、文字或其他内容。勾选“显示全部时间轴（含零件）”可查看其他元件。推荐依据不是完整角色或身份的审核结果。
3. 设置起始帧、结束帧和步长，点击“导出并建立待筛候选”。帧号从 1 开始，默认步长为 1，即逐帧。一次最多接收 2048 个画面；当前库元件的原生序列导出还要求整个元件时间轴不超过 2048 帧。
4. 在任务页查看进度。完成后点击“刷新已导出画面”打开工程画面，或“进入 M02 筛选”，继续原有的保留／排除、角色框、样本生成和姿态标注流程。

导出只生成待判断候选，不把腿、眼睛等零件自动当成完整角色，也不自动审核姿态。重新接收相同画面会保留已有人工决定。本轮没有自动挑选代表帧或折叠相似画面的功能。

程序保留独立工作副本、导出请求、脚本、回执及图像，并核对原工程版本和输出位置。不会保存或覆盖原 FLA。M09 可回到已导出的工程画面、定位原文件、复制元件／场景名称和帧号；尚不替用户在 Animate 内自动跳到该角色实例。

没有找到 Animate 时，窗口显示原因并禁用自动导出；现代工程结构和已导出画面仍可查看。可通过进程环境变量 `PONY_ANIMATE` 指向本机已有的 Animate 可执行文件，不会自动安装组件或修改系统信任设置。

Animate 首次处理 JSFL 时可能询问“运行还是编辑”，本流程需选择**作为命令运行**。打开旧版 ActionScript 2（AS2）工程可能出现转换提示，操作对象是工作副本，程序不保存回原件。当前导出用于查看时间轴的静态画面，不保证旧脚本驱动的播放效果。遇到提示时需在 Animate 中处理；任务等待超时后，已有成功回执仍可接收。

暂停队列只暂停程序等待与接收，**不会停止已经启动的 Animate**。未开始的任务可以取消；已有失败回执时，请回到角色工程窗口重新建立导出任务，旧副本和诊断会保留。等待超时不等于原生导出已经停止，程序不会盲目重复投递；收到回执后可在任务页重试接收。

M01 的“目录与任务管理”可以配置排除项、重新定位根目录和导出编目；耗时任务统一显示在“任务与日志”。`scripts/m12/catalog_sources.py` 保留兼容子命令，读写相同目录。

视频工具可通过进程环境 `PONY_FFMPEG` 和 `PONY_FFPROBE` 显式指定现有可执行文件；不自动下载、安装或修改系统设置。
