Pony Pose Search 0.1.0 · Windows 64 位免安装版

1. 右键下载的 ZIP，选择“全部解压”，选择一个普通文件夹。
2. 打开解压出来的 PonyPoseSearch 文件夹，双击 PonyPoseSearch.exe。
   必须保留旁边的 _internal 文件夹，不要只把 exe 单独移走。
   不需要另装 Python、FFmpeg，也不需要管理员权限。
3. 新用户第一次打开时素材数量是 0，这是正常的。下载包没有附带角色素材或标注库。

第一次尝试，先用一张只含一个角色的 PNG/JPG：
M01 → 添加文件 → 选中图片 → 读取画面 → 选整张图 → 确认框内是一个角色
→ 选择角色形态 → 建立记录 → 标注。
M05 切到“直接方向”模式，选中要标的方向，在图上拖出箭头。
画完会自动前进到下一项；点回刚才画的那一项，点“确认此方向”，等待保存。
再加入另一张图片，做同样的标注。
选择一条已标记录 → 搜索此姿态 → M08 → 搜索并查看结果 → M09 查看结果。
M09 可查看原文件、帧号、角色区域，并在文件夹中选中原素材。
只是添加文件还不能搜索姿态，必须先建立角色记录并保存可比较的标注。

资料库默认保存在：%LOCALAPPDATA%\PonyPoseSearch\library
将这行路径粘贴到文件资源管理器地址栏，即可打开。
可在窗口上方“切换资料库…”选择其他位置，程序会记住选择。
更换新版程序前，请关闭窗口。下载新版并解压到新的文件夹即可。
标注保存在资料库里，不放在程序安装目录；仍建议定期备份整份资料库和原素材。
删除程序文件夹不会删除资料库。

视频：已带所需组件，在 M01 选视频、输入帧号读取，或使用“批量选帧…”。帧号从 1 开始。
FLA：需要另行安装 Adobe Animate。在 M01 点“角色工程…”，选场景或角色元件并导出。
AI：模型和 AI 训练环境需要另外准备。没有 AI 仍可手动标注并搜索，不影响上述流程。
