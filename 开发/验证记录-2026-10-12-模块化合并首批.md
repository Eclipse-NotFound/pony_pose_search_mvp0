## 实现与运行影响

- `scripts/common/workflow/project.py`：共同项目/库选择和模块登记；M07 查询追加保存、完整条件校验，M08 记录当次候选修订和结果，M09 导出冻结结果。标注仍由 `Library.edit/save` 写入，无第二套方向保存实现。
- `scripts/common/workflow/inventory.py` 与 `scripts/dataset/audit_workflow.py`：只读盘点及显式独立复制。保留编号与修订；管理内图片改为副本路径，库外图片保留引用；SQLite 使用备份接口。复制失败或原库有未完成入库时保留未完成标记，禁止打开半成品副本。
- `scripts/m10/workbench_model.py`：仅保留编辑草稿、选择和界面会话状态，查询、搜索和导出交给共同操作。过期加载版本不能作为当前标注直接建立查询；M08 默认读取资料库最新保存的查询。
- `scripts/m10/native_workbench.py`：增加保存查询、执行已存查询、比较权重和离线 HTML；恢复保存的查询及结果；调整布局，保证 1100×740 窗口中来源和导出按钮可见。
- `scripts/m10/control_center.py`：M05 方向、M07、M08、M09 的原 Run 按钮转向同一原生工作区，模块状态读取实际库记录。项目切换检查待保存与运行任务；`--library` 与原 `--workbench-library` 共用同一选择。隐藏旧搜索参数页并去除无效的旧 M08 重置按钮，消除重复的任务完成方法定义。
- 原四个模块 CLI 通过 `--workflow` 调用同一实现，无开关的旧文件链保留。`dataset/pose_library.py` 搜索及兼容网页也共用查询/搜索/结果导出；网页必须按已有 `run_id` 导出，不在导出时重算。

M01—M04、M06、旧 schema 点位与 AI/训练尚未迁移。两个主标签、旧 CLI 与网页兼容入口仍存在，不能把本批称为全部旧路径退役。当前 M10 默认使用既有 `data/pose_library_v2/`；用户后续正常保存会写入所选库，但本轮验证均显式选择隔离库。

行为断言覆盖：

1. M05 保存新方向后，M07 使用同一标注版本，M08 得到预期方向分数；原四个脚本的真实子进程调用与原生界面读取同一结果。
2. 真实 Tk 中触发 M05→M07→M08→M09 的原模块按钮；不启动旧 GUI 来完成共同方向流程。历史只读、未保存阻断、并发覆盖保护仍有效。
3. 查询保存后由另一个入口更新当前查询，M08 读取最新共享查询；另一个入口更新标注后，过期编辑会话不能直接把旧加载版本当成当前版本保存查询。
4. 搜索后修改候选，再导出仍使用搜索时的版本和分数；重开会话可恢复结果；目录定义变化使旧查询要求重存，损坏的结果拒绝导出。
5. 非法筛选、开关、权重和集合在保存前被拒绝，不生成半份查询；HTML 转义素材名，CSV 对公式前缀作处理。
6. 隔离副本保留编号、修订和受管图片；重复目标拒绝覆盖，未完成复制不能启用；原来源修改且新库已有后续修订时报告冲突，不覆盖任一侧。
7. 兼容网页在搜索后标签发生变化时，按 run_id 导出所见结果；旧请求体没有 run_id 时明确拒绝。

## 检查中发现并处理的问题

- 兼容网页下载路由只接受旧 `hits_` 文件名，改为接受共同结果的 `run_` 后，真实下载回归通过。
- 全局“Refresh Status”原先会把共同模块状态临时换成旧文件状态，改为跳过这些模块的旧文件判断，从所选资料库统一刷新；原模块按钮的回归检查加入了全局刷新后的状态断言。
- 小窗口中结果说明和底部来源操作被挤出视野，调整为先安排固定操作区，再给列表/图片分配剩余空间。截图检查时 M07/M08 按钮位于 y=666—690，底部操作可见。
- 默认沙箱临时目录、Tk 多解释器及回环网络限制曾使检查失败。最终把临时目录限定于项目实验目录，Tk 使用单解释器生命周期，HTTP 检查通过已批准的本地执行完成；没有改系统安装或网络设置。
- 视频测试对当前进程显式指定本机现有 FFmpeg / ffprobe，避免沙箱用户目录重定向导致找不到已安装程序。未做系统级环境变量变更。
- 旧 `test_model_yaml_kpt_shape_replaced` 仍因未安装 ultralytics 失败。该训练构建器不属于本批合并修改；训练链路在 D 阶段适配和验证，当前不承诺可训练。

测试完整终端输出来自本轮工具调用，未另存全量日志；上述 JSON、HTML 和截图是实际生成文件。10 个相关 Python 文件语法检查、两份修改的网页脚本语法检查及 6 份文档链接检查通过。`git diff --check` 通过，提示仅为既有换行设置。
