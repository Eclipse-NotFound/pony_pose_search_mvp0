# Windows 免安装发行版验证

日期：2026-10-14。目标：发布无需配置 Python／FFmpeg 的 Windows 下载包，并改写零基础用户的安装使用说明。

## 实际交付

首个版本 `v0.1.0`，程序包 `PonyPoseSearch-0.1.0-Windows-x64.zip`。从 ZIP 完整解压后双击 exe；不要求管理员权限，不执行安装或替用户接受系统信任提示。使用 Windows 11 x64、Python 3.12、PyInstaller 6.22.3、Pillow 12.3.0 构建。

源码、元数据与随包组件从公开源码白名单目录构建，未收集原始素材、私人标注、权重或实验缓存。公开分支沿 `github-main` 继续提交，没有推送含历史裁剪素材的本地 `main`。

基础软件与资料库分离：发行版写 `%LOCALAPPDATA%/PonyPoseSearch`，源码版沿用项目内原库；成功切换的资料库可记住。Animate 请求状态也在用户目录。AI 解释器选择明确排除发行版 exe，无独立 AI 环境时给出说明。README 和用户指南说明下载附件、完整解压、第一张图、两图搜索、审核、视频与 FLA、备份更新和常见问题。

## 验证结果

- 最终源码回归：`tests/multispecies tests/m10` **215 passed, 1 skipped**，99.07 秒。跳过项为沙箱不允许创建真实 Windows 目录联接；相关逻辑测试仍执行。证据：`.probe/release-20261014/regression-2.log`。
- 最终 ZIP 解压到中文与空格路径。仅保留 Windows 系统 PATH，Python 环境路径指向不存在的位置，移除外部 FFmpeg／AI 覆盖变量；可打开九个模块，建立空资料库。
- 使用包内 FFmpeg/ffprobe，从自生成 PNG、MP4 建立 2 条姿态记录，审核头部方向，搜索得到 1 条候选；原视频第 3 帧的来源信息正确。CSV、JSON、离线 HTML 均导出成功，视频播放代理生成成功。
- 第二次启动自动读回选中的两条记录资料库。程序文件夹所有文件 SHA-256 前后完全一致，无运行数据写入程序目录。
- JSFL 模板随包存在；本次不操作 Animate，原生 FLA 导出证据沿用此前工程副本验证。未宣称在全新 Windows 10 机器、不同显卡与所有素材编码上全面验收。
- 最终 ZIP SHA-256：`75555f0d2791e1a0f855be6ab4d193a698d59953c945dc054fedff9b9aa650b9`。完整回执：`.probe/release-20261014/qa-5/verification.json`；构建目录：`.probe/release-20261014/build-4`。

## 构建中修复的问题

1. 项目业务包 `workflow` 与 PyInstaller 第三方 hook 同名，导致构建错误。增加本地 hook 并显式收集业务子模块；未修改全局打包工具。
2. 选用的 LGPL FFmpeg 构建缺少 zlib/PNG 编码，但支持无压缩 TIFF、常见视频解码与 OpenH264。精确取帧改为无压缩 RGBA TIFF 管道，由 Pillow 写 PNG；发行版播放代理使用 OpenH264。原旋转、视频流与帧号测试通过，未用有损 JPEG 中转。
3. 同时保留给冻结模块与外部 Python worker 使用的 JSFL 资源位置；实际成品自检拦住了首次漏收模板，补齐后通过。
4. 随包保留 Python、Tcl/Tk、Pillow、PyInstaller 和视频 DLL 许可；FFmpeg 原包缺失的 GCC 运行库例外文本从上游补齐。对应 FFmpeg 源码与构建脚本作为同版 Release 附件提供。

以上结果是本机隔离配置下的真实 exe 验证，不是凭源码测试推断可分发。具体发布回执保存在 `.probe/release-20261014/published.json`。
